# artys-snake
The classic game Snake done in vanilla HTML, CSS and JavaScript

The layout is done with CSS grid. Check `ArtysSnakeGame.buildHTML()` for more details

The rows and columns can be changed via constructor params (minimum 5 rows and 5 columns) `constructor(container, rows, columns)`

The snake head is an edited version of this Pac-Man css shape https://css-shape.com/pacman/

The egg png is by Bas de Reuver (www.bdrgames.nl, bdr1976@gmail.com) found at https://opengameart.org/content/snake-sprites-2d
